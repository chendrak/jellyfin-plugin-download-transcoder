Download Transcoder

Activity and progress

When a client downloads a video (for example with the download button in the Jellyfin mobile app), this plugin sends a smaller, transcoded MP4 instead of the original file. Add ?original=true to a download URL to get the original anyway.

Profiles

Each download uses one profile. The server picks it in this order: a device you assigned below, then a profile whose "match names" fits the app or device name, then the detected kind of device (phone, tablet, TV, computer), then the "Other" profile.

Shared options

Uses the type and device set under Dashboard, Playback, Transcoding (NVENC, Quick Sync, VAAPI, VideoToolbox, AMF…) with "Enable hardware encoding" turned on. A profile's libx264 becomes h264 on the GPU and libx265 becomes HEVC on the GPU. If the GPU fails, the CPU takes over. The activity page shows which one was used.
Much faster for 4K, HEVC and HDR sources. If a file fails this way, it is retried with GPU encoding only, then on the CPU.

Devices

Devices that have signed in to this server, what the server detected them as, and which profile their downloads use. Pick a profile to override detection for one device. Save to apply.

When no smaller copy is ready yet

The official Jellyfin Android app needs the file size before it starts and retries on its own, so it always gets "retry later" even in live mode. Its download finishes on a later retry, usually within a few minutes. Live downloads have no known size, and some players can't seek in them. Pre-transcoding makes downloads instant.

Cache and pre-transcoding

Finished transcodes are kept so the next download is instant. 0 turns the cache off.
Empty uses Jellyfin's cache folder.
Takes effect after a server restart.

Pre-transcode the newest items in these libraries

The "Pre-transcode downloads" scheduled task runs daily at 3 AM. You can run it now from Dashboard, Scheduled Tasks.

Advanced

Placed before -i, e.g. "-hwaccel vaapi -hwaccel_device /dev/dri/renderD128 -hwaccel_output_format vaapi".
Replaces the built-in scale and tone-map filter, e.g. "scale_vaapi=w=-2:h={height}" for VAAPI. {height} is the maximum height.
