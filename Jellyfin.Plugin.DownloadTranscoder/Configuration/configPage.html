Download Transcoder

When a client downloads a video (for example with the download button in the Jellyfin mobile app), this plugin sends a smaller, transcoded MP4 instead of the original file. Add ?original=true to a download URL to get the original anyway.

Quality

480, 720 or 1080 are typical. Smaller sources are never upscaled.
About 0.9 GB per hour at 2000 kbit/s.
libx264 (H.264, plays everywhere), libx265 (HEVC, smaller), or a hardware encoder such as h264_nvenc, h264_qsv, h264_vaapi, hevc_videotoolbox.
For libx264/libx265: ultrafast to veryslow. Slower is smaller but takes longer. Leave empty for encoders without presets.
2 downmixes surround to stereo, which suits phones and headphones.

Which downloads

App names as shown under Dashboard, Devices, e.g. "Jellyfin Android". Empty means every app.
e.g. "Jellyfin Web" to keep original downloads from the browser.

When no smaller copy is ready yet

Live downloads have no known size, so apps cannot show a percentage. Some players cannot seek in a live-transcoded MP4; a pre-transcoded copy always can.

Cache and pre-transcoding

Finished transcodes are kept so the next download is instant. 0 turns the cache off.
Empty uses Jellyfin's cache folder.
Takes effect after a server restart.

Pre-transcode the newest items in these libraries

The "Pre-transcode downloads" scheduled task runs daily at 3 AM. You can run it now from Dashboard, Scheduled Tasks.

Advanced

Placed before -i, e.g. "-hwaccel vaapi -hwaccel_device /dev/dri/renderD128 -hwaccel_output_format vaapi".
Replaces the built-in scale and tone-map filter, e.g. "scale_vaapi=w=-2:h={height}" for VAAPI. {height} is the maximum height.
