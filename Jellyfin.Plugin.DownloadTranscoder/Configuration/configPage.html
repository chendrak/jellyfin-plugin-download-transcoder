How a profile is chosen

1. The override above. 2. A profile whose "also use for" names match the app or device. 3. The recognised kind of device. 4. The "Other" profile.

GPU

Intel or AMD with Quick Sync or VAAPI on Linux. Falls back automatically if a file can't be handled this way.
Takes effect after a server restart.

Prepare ahead of time

A nightly task (3 AM) makes small copies of the newest items, so downloads start instantly.

Storage

Small copies are kept so the next download is instant. Oldest are removed first. 0 keeps nothing.
